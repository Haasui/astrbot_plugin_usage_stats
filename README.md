# 用量统计

AstrBot 文本模型用量统计插件。按来源插件、模型提供方和时间查看调用次数、Token、缓存与估算费用，帮助你找到模型调用的主要消耗来源。

- 在 Web 页面查看总览、趋势、排行、请求明细和价格统计。
- 在管理页保存采集开关、明细记录和保留设置。
- 用管理员聊天指令快速查看汇总。
- 按需保存调用明细或文本日志，均不主动记录消息正文。

## 开始使用

项目元数据声明支持 AstrBot **4.11.0 及以上**。Web 管理页需要宿主提供插件页面 Bridge 和配置保存接口；兼容说明见[使用指南](<docs/USAGE.md#安装与启用>)。

1. 在 AstrBot 插件管理中安装本仓库：
   ~~~text
   https://github.com/Haasui/astrbot_plugin_usage_stats
   ~~~
2. 加载插件，打开它提供的 **用量统计** 页面。
3. 在 **数据管理** 中开启 **启用用量采集**，点击 **保存设置**。
4. 发起一次文本模型调用，刷新总览；也可发送管理员指令：
   ~~~text
   /usage
   ~~~

需要逐调用记录和性能统计时，再开启 **保存调用明细**。旧日汇总不会自动变成明细。

## 页面能做什么

| 页面 | 用途 |
| --- | --- |
| 总览 | 查看调用量、Token、成功率、缓存、性能样本和估算费用 |
| 分析 | 按插件、模型或 provider 比较用量，并下钻筛选 |
| 请求明细 | 查看单次记录、调整列、分页及导出匹配的 CSV |
| 价格统计 | 查看模型用量和费用，更新 Models.dev 参考价或维护手工覆盖 |
| 调用日志 | 按需读取可选文本日志，检查请求构成长度和耗时 |
| 数据管理 | 保存采集设置、查看数据覆盖、展开运行诊断或重置统计 |

页面顶部的统一筛选用于统计、分析、明细和导出。调用日志是独立的有界尾读，不使用这些统计筛选。

## 先了解这三点

- **采集范围**：记录经过当前 AstrBot 进程中 provider 文本生成方法的调用，不是供应商侧的全部 HTTP 请求或重试账单。
- **数据覆盖**：Token 依赖返回的 usage，性能依赖可用明细。未上报字段与明确的零值不是一回事。
- **费用估算**：价格统计使用 USD / 百万 Token。公共目录不匹配自定义模型名时可手工设价；估算不能替代供应商账单。

具体口径、明细与日志的区别，以及备份和重置范围，见[使用指南](<docs/USAGE.md>)。
