Token 构成

哪些 Token 计入总量？

总量 = 未缓存输入 + 缓存读取 + 输出。

推理和缓存写入可能已包含在输入或输出中，因此不再重复计入总量。是否计费取决于提供方。

性能与覆盖

平均 TPS
平均 TPS 怎么算？

有输出 Token 和有效耗时的成功调用才参与计算。用这些调用的输出 Token 总数除以总耗时，不是逐次 TPS 的简单平均。

—输出 Token/秒
缓存命中率
这两个缓存比例有什么区别？

缓存命中率 = 缓存读取量 ÷ 输入总量。

缓存读取占总 Token 的比例以输入和输出之和为分母。两项都只使用缓存统计完整的样本。
